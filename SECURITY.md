# Security policy

Do not open a public issue for vulnerabilities or include credentials, private
portal URLs, student data, or exploit details in public discussions.

Report vulnerabilities through **Report a vulnerability** on the main
[Study Buddy Security page](https://github.com/HabsaTheDog/StudyBuddy/security).
Include the affected interface commit, impact, and a synthetic reproduction.

Study Buddy is currently in alpha. Security fixes target the current parent
default branch and newest prerelease; older fork commits are unsupported. The
complete security boundary and credential-incident process live in the main
[security policy](https://github.com/HabsaTheDog/StudyBuddy/blob/master/SECURITY.md).
